GitHub Webhook Kurulumu

GitHub deponuzda commit veya PR birleştiğinde sürüm notlarınızın otomatik üretilmesi için deponuzun Settings → Webhooks → Add webhook sayfasına aşağıdaki bilgileri girin:

Payload URL:
{{ app_url }}/api/v1/webhook
Content type:
application/json

Depoya Özel Gizli Anahtar (Secret):

Her deponuz için bağımsız ve şifreli bir webhook anahtarı üretilir. GitHub'daki Secret alanına ilgili deponuzun anahtarını yapıştırın:
